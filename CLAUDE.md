# CL Security Survey

## Project objective
Develop a scientific survey on security attacks and defenses in Continual Learning (CL).

## Project structure
- `literature/`: original scientific papers and literature summary tables.
- `taxonomy/`: proposed taxonomies and classification schemes.
- `extra/`: supplementary materials that may be useful later.
- `CL_Security_Survey/`: local copy of the Overleaf project.
- `docs/`: project documentation, research notes, analysis, and writing plans.

## General rules
- Treat original scientific papers as the primary sources of evidence.
- Use summary tables as indexes to the literature, not as substitutes for the original papers.
- Never invent references, results, or technical details.
- Distinguish verified facts from interpretations and unresolved questions.
- Do not modify original papers or silently change established scientific decisions.
- Before writing or modifying the manuscript, analyze the available materials and propose a plan.
- Ask for approval before making substantial changes to the scientific argument.
- Keep documentation organized under `docs/`.
- Report uncertainties and unresolved questions explicitly.
